One line about office life, written to be funny on its own: the
printer that only ever jams when the deadline is real.

## The joke

> Our printer only jams when the deadline is real. It can smell fear,
> and it runs on toner and tears.

It is a real joke about the office (the machine that senses urgency),
it turns on the last few words, and it stays tight at 99 characters,
inside the 200-character limit.

## Run it

```bash
python3 main.py
```

This writes the joke to `/output/entry.txt` (UTF-8, one line, no
trailing newline). Only the Python standard library is used, so the
output is identical on every run.

Entrypoint: `python3 main.py` — no arguments, no setup step.
